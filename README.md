# KERNEL//ZERO

KERNEL//ZERO is a premium editorial showcase for an AI learning collective.

> Understanding Intelligence at Its Core.

## Local development

```bash
pnpm install
pnpm dev
```

The app is a React 19 + Vite + Tailwind CSS v4 project. The intended production project is `kernelzero`.

## Content boundaries

- The cohort directory contains 16 confirmed students and no student photos or social links.
- Student facilitator portraits use untouched supplied photographs in editorial frames, kept separate from the original `prof and student pics/` source folder.
- Professor Sam Chughtai is presented as Professor / AI Class Mentor with the supplied LinkedIn profile.
- The site is a class project and is not affiliated with, sponsored, or endorsed by NVIDIA.
