# KERNEL//ZERO

KERNEL//ZERO is a premium editorial showcase for an artificial intelligence class collective at National University – Fairview.

> Understanding Intelligence at Its Core.

## Local development

```bash
pnpm install
pnpm dev
```

The app is a React 19 + Vite + Tailwind CSS v4 project. The existing deployment URL remains `https://nvgenesis.vercel.app/`; this rebrand does not rename the repository, change DNS, or alter Vercel settings.

## Content boundaries

- The cohort directory contains 16 confirmed students and no student photos or social links.
- Student facilitator portraits are supplied local assets, processed into `public/portraits/`, and kept separate from the original `prof and student pics/` source folder.
- Professor Sam Chughtai is presented as Professor / Class Mentor with the supplied LinkedIn profile.
- The site is a class project and is not affiliated with, sponsored, or endorsed by NVIDIA.
